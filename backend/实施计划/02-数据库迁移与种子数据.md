## 环境约束（重要）

本机 Prisma CLI 拉取引擎超时（既往已验证）。因此：
- 迁移文件**在 CI 生成**：CI 作业用临时 Postgres 执行 `npx prisma migrate dev --name init` 生成 `migrations/`，再将生成的文件提交回仓库。
- 本机只写 `schema.prisma` / `seed.ts` 代码；不在本机跑 `prisma generate/migrate`。
- 依赖真实 DB 的测试（本步冒烟、后续全部集成/并发/E2E）一律 CI 执行。

import { DEMO_ADMIN, DEMO_USER, COURSE_TYPESCRIPT, COURSE_WRITING,

describe('迁移与种子冒烟（CI）', () => {
  let prisma: PrismaClient;
  beforeAll(async () => { prisma = new PrismaClient(); });

  it('全部核心表可查询', async () => {

    const admin = await prisma.user.findUnique({ where: { email: DEMO_ADMIN.email } });
    expect(admin?.role).toBe('admin');
    expect(admin?.status).toBe('active');
    const user = await prisma.user.findUnique({ where: { email: DEMO_USER.email } });

    expect(c?.type).toBe('video');
    expect(await prisma.chapter.count({ where: { courseId: c!.id } })).toBe(2);

  it('course-writing 为草稿图文课，不出现在用户端', async () => {
    const c = await prisma.course.findUnique({ where: { id: COURSE_WRITING.id } });
    expect(c?.status).toBe('draft');
    expect(c?.type).toBe('rich');

  it('进行中双人拼团活动 + 仅差一人团组（含待成团订单）', async () => {

    expect(act?.targetSize).toBe(2);
    const g = await prisma.grouponGroup.findUnique({ where: { id: GROUPON_GROUP_ONE_SHORT.id } });
    expect(g?.status).toBe('pending');
    expect(g?.memberCount).toBe(1);

    const order = await prisma.order.findUnique({
      where: { id: (await prisma.grouponMember.findFirst({ where: { groupId: g!.id } }))!.orderId } });

时间规则（种子内计算，以服务端时间为准）：
- 拼团活动：`startAt = now - 1h`，`endAt = now + 3h` → 天然 `ongoing`（配合任务 4 的状态流转任务保持）。

- [ ] **2.4 实现 `prisma/seed.ts`**

```ts
import { PrismaClient } from '@prisma/client';
import { loadConfig } from '../src/config/configuration';
import { DEMO_ADMIN, DEMO_USER, COURSE_TYPESCRIPT, COURSE_WRITING,
         GROUPON_ACTIVITY, FLASH_SALE_ACTIVITY, COUPON_TEMPLATE, GROUPON_GROUP_ONE_SHORT } from './seed-data';

async function main() {
  const cfg = loadConfig();
  if (!cfg.seedDemoData && process.env.NODE_ENV === 'production') {
    console.log('prod 环境不注入演示数据，跳过');
    return;
  }
  const prisma = new PrismaClient();
  // 全部 upsert：账号按 email、课程按固定 id、活动按固定 id、券按固定 id、团组按固定 id
  const admin = await prisma.user.upsert({ where: { email: DEMO_ADMIN.email },
    create: { ...DEMO_ADMIN, passwordHash: await bcrypt.hash(DEMO_ADMIN.password, 12) },
    update: {} });
  // admin 生成 TOTP 密钥（步骤 03 才启用校验，先落字段）——本步先打印到控制台
  // 其余实体同模式 upsert；课程章节按 (courseId, sortOrder) upsert；
  // 团组成员按 (groupId, userId) upsert，订单按 orderNo 固定 'GRP-DEMO-0001' upsert（status=paid，
  // purchaseKey 非空、flashPurchaseKey 为 null、payment 一条 success 记录）
  console.log(`admin TOTP 种子完成：${admin.email}（密钥见步骤 03 落库后）`);
}

main().catch(e => { console.error(e); process.exit(1); });
```

关键点：
- 演示账号密码哈希用 `bcrypt.hash(password, 12)`（D10，cost≥12）；**prod 严禁注入演示账号**——`seedDemoData=false` 时跳过（dev/staging 设 `SEED_DEMO_DATA=true`）。
- 全部写操作用 upsert（幂等）；关联写操作（章节/成员/订单）按唯一键 upsert。
- 种子中「仅差一人」团组订单：`activityType=groupon`、`activityId=团组id`、`purchaseKey='user:{DEMO_USER.id}:course:1'`、状态 `paid`，`payments` 一条 `success` 记录（渠道 `mock`、`transactionNo='MOCK-SEED-GRP-0001'`）。
