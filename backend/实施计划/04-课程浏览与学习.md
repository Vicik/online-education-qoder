> 总览：[实施计划 README](./README.md) · 前置：步骤 03 · 后继：步骤 05

async hasPaidAccess(userId: number, courseId: number): Promise<boolean> {
  const order = await this.prisma.order.findFirst({
    where: { userId, courseId, status: 'paid',
      OR: [
        { activityType: { not: 'groupon' } },
        { grouponMembers: { some: { group: { status: 'success' } } } },
      ] },
  });
  return order !== null;
}

```ts
async getChapterContent(userId: number, courseId: number, chapterId: number) {
  const chapter = await this.prisma.chapter.findFirst({ where: { id: chapterId, courseId } });
  if (!chapter) throw new BizException(3001, '章节不存在', 404);
  if (!(await this.hasPaidAccess(userId, courseId)))
    throw new BizException(3002, '请先购买课程', 403);      // 未购仅可看章节名（列表/详情接口提供）
  return { id: chapter.id, title: chapter.title, contentType: chapter.contentType, content: chapter.content };
}
```

```ts
async recordVisit(userId, courseId, chapterId) {
  if (!(await this.courseService.hasPaidAccess(userId, courseId)))
    throw new BizException(3002, '请先购买课程', 403);
  const total = await this.prisma.chapter.count({ where: { courseId } });
  if (total === 0) throw new BizException(3001, '章节不存在', 404);
  await this.prisma.learningRecord.upsert({
    where: { userId_chapterId: { userId, chapterId } },
    create: { userId, courseId, chapterId }, update: { visitedAt: new Date() } });
  const visited = await this.prisma.learningRecord.count({ where: { userId, courseId } });
  return { progressPercent: Math.round((visited / total) * 100), completed: visited >= total };
}
```

`getStudyRecords`：按 `learning_records` 聚合（`groupBy courseId` 取最近 visitedAt 章节与课程信息），`progressPercent` 同公式；无手动「已学完」按钮（completed 由进度自动判定）。
路由：`POST /learning/:courseId/chapters/:cid/visit`、`GET /user/study-records`（均登录）。
