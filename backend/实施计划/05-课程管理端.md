- [ ] **3.2 运行确认失败**；**3.3 实现**

```ts
const PUBLISH_EDITABLE = ['instructor', 'coverUrl', 'intro', 'detailRich'];   // 已发布仅这些字段
const DRAFT_EDITABLE = ['name', 'type', 'originalCents', 'saleCents', ...PUBLISH_EDITABLE];
async update(courseId, dto) {
  const course = await this.prisma.course.findUnique({ where: { id: courseId } });
  if (!course) throw new BizException(3001, '课程不存在', 404);
  const editable = course.status === 'published' ? PUBLISH_EDITABLE : DRAFT_EDITABLE;
  for (const k of Object.keys(dto)) if (k !== 'version' && !editable.includes(k))
    throw new BizException(1001, `课程「${course.status}」状态不可修改该字段，请先下架`, 422);
  const data = pick(dto, editable);                                    // 白名单取值
  if (data.detailRich) data.detailRich = sanitizeRichHtml(data.detailRich);
  if (dto.saleCents != null && dto.saleCents > course.originalCents) throw new BizException(1001, '售价不得高于原价', 400);
  const { count } = await this.prisma.course.updateMany({ where: { id: courseId, version: dto.version }, data });
  if (count === 0) throw new BizException(4004, '数据已被修改，请刷新后重试', 409);
  await this.audit.log({ actorId, action: 'course.update', targetType: 'course', targetId: courseId, before: course, after: data });
  return this.prisma.course.findUniqueOrThrow({ where: { id: courseId } });
}
```

> 乐观锁用 `updateMany({ where: { id, version } })` 计数判断；`version` 自增交由 Prisma `version: { increment: 1 }`（并入 `data`）。
> 注意：DTO 全字段可选 + `version` 必填（openapi CourseUpdateRequest）。

    where: { id }, data: { sortOrder: i + 1 } })));

- [ ] **5.2 运行确认失败**；**5.3 实现**

- `addChapter`：课程必须 `draft|unpublished`（已发布抛「请先下架」422）；`contentType === course.type`（首个章节后类型锁定，schema 无锁字段——锁定由「已发布课程不可改类型 + 草稿改类型前无章节」双重保证：**改类型时若有章节则拒绝**（`update` 中补此规则））；`sortOrder = (max ?? 0) + 1`；`content` 若 `rich` 先净化。
- `updateChapter`：类型不可改（继承课程类型）；`rich` 内容净化；已发布课程禁止（先下架）。
- `deleteChapter`：仅 `draft|unpublished`；删除后重编号（复用 reorder 逻辑）。
- `reorderChapters`：校验 `orderedIds` 与现有章节集合一致（缺/多/重复抛 1001）；两阶段：`updateMany({ where: { courseId }, data: { sortOrder: { increment: 1000 } } })` → 按序逐条 `update({ where: { id }, data: { sortOrder: i + 1 } })`（避开 `(courseId, sortOrder)` 唯一约束冲突）；仅 `draft|unpublished` 可排序。
- 章节写操作审计：`chapter.create/update/delete/reorder`（before/after 记章节列表）。
- `course.admin.controller.ts`：全部路由挂 `RolesGuard('admin')` + `/api/v1/admin` 前缀（全局前缀 + controller 前缀 `admin/courses`），与 openapi 路径逐条对齐。
