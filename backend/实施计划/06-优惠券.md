# 步骤 06：优惠券

> 总览：[实施计划 README](./README.md) · 前置：步骤 05 · 后继：步骤 07

**目标**：实现优惠券模板管理（管理端）与领取/我的券（用户端）（§7.4）——模板创建/编辑/启停（**停用级联已失效**）、限领（每模板每用户一张，`claimKey` 可空唯一列）、防超发（条件更新）、领取幂等。

**完成标准**：
- [ ] 接口：`/courses/:id/coupons`、`/coupons/:templateId/claim`、`/user/coupons`、`/admin/coupons`（GET/POST）、`/admin/coupons/:id`（GET/PUT）、`/admin/coupons/:id/enable|disable` 与 openapi.yaml 一致
- [ ] 限领语义（接口设计文档 §9.3 已决）：同一启用周期任何未失效记录（未使用/已使用/已过期）都阻止再领；模板停用致记录变「已失效」后可重领
- [ ] 发放总量只计未失效记录，条件更新防超发；幂等键防重复领取
- [ ] 停用级联：未使用/已恢复 → 已失效（永久），已使用保留；重新启用不恢复
- [ ] 本机单元测试全过；CI 集成测试全绿

- [ ] **2.2 运行确认失败**；**2.3 实现**

```ts
async claim(userId, templateId, idempotencyKey) {
  return this.idempotency.run(userId, idempotencyKey, 'POST /coupons/claim', async () => {
    const tpl = await this.prisma.couponTemplate.findUnique({ where: { id: templateId } });
    if (!tpl || tpl.status !== 'enabled') throw new BizException(4002, '优惠券不可领取', 422);
    const now = new Date();
    if (tpl.startAt > now || tpl.endAt < now) throw new BizException(4002, '不在领取有效期', 422);
    // 限领（§9.3 已决）：任何未失效记录都阻止再领（claimKey 非空即存在未失效记录）
    const existing = await this.prisma.couponClaim.findFirst({
      where: { templateId, userId, claimKey: { not: null } } });
    if (existing) throw new BizException(1001, '该优惠券每人限领一张', 409);
    // 防超发：条件更新 claimedCount
    const { count } = await this.prisma.couponTemplate.updateMany({
      where: { id: templateId, claimedCount: { lt: tpl.totalQty } },
      data: { claimedCount: { increment: 1 } } });
    if (count === 0) throw new BizException(4002, '优惠券已被领完', 422);
    try {
      return await this.prisma.couponClaim.create({ data: { templateId, userId,
        claimKey: `template:${templateId}:user:${userId}` } });
    } catch (e: any) {
      if (e.code === 'P2002') throw new BizException(1001, '该优惠券每人限领一张', 409);
      throw e;
    }
  });
}
```

要点：claimKey 的 `@unique` 即部分唯一索引适配；「已失效」记录 claimKey 为 NULL，不阻止再领；`listMine` 支持 `status` 筛选（unused/used/expired/invalid）；`redeemInTx`/`restoreInTx` 本步只定义签名与简单实现（事务内 `updateMany` + 状态校验），真正核销调用在步骤 07。
路由：`GET /courses/:id/coupons`（公开）、`POST /coupons/:templateId/claim`（登录 + Idempotency-Key）、`GET /user/coupons`（登录）。
