```ts
export function gradeSingle(correct: string[], user: string[]): number {
  return correct.length === 1 && user.length === 1 && correct[0] === user[0] ? 1 : 0;
}
export function gradeMultiple(correct: string[], user: string[]): number {
  if (correct.length !== user.length) return 0;
  return correct.every(c => user.includes(c)) ? 1 : 0;      // 长度相等且全包含 = 完全匹配且无错选
}
export function gradeAttempt(snapshot, answers) {
  let score = 0; const total = snapshot.reduce((s, q) => s + q.score, 0);  for (const q of snapshot) {
    const hit = q.type === 'single' ? gradeSingle(q.answer, answers[String(q.questionId)] ?? [])
                                    : gradeMultiple(q.answer, answers[String(q.questionId)] ?? []);
    if (hit) score += q.score;
  }
  return { score, total };
}
```

```ts
async publish(examId) {
  const exam = await this.prisma.exam.findUnique({ where: { id: examId } });
  if (!exam || exam.status !== 'draft') throw new BizException(1001, '仅草稿考试可发布', 422);
  // questionIds 存于哪里？—— Exam 模型无 questionIds 列！
}
```

> **Schema 缺口处理**：`Exam` 模型只有 `snapshot Json?`，组卷的选题关系（questionIds + 顺序）需落库。两个方案：① 草稿期把选题与顺序存在 `snapshot` 里（发布时只补 answer/analysis 并置 status）——但「发布时冻结」语义要求草稿可改；② 加关联表。**选①**：草稿期 `snapshot` 存 `[{ questionId, type, stem, options, score, sortOrder }]`（无 answer/analysis），发布时读题库合并 answer/analysis 写回快照并 `status='published'`。选①不动 schema，快照即组卷，与 schema 注释一致。
> `publish` 实现：读 `exam.snapshot` 的 questionId 列表 → `question.findMany({ where: { id: { in } } })` → 合并成完整快照（含 answer/analysis）→ `update({ data: { snapshot: merged, status: 'published', publishedAt: now } })`。题库后续修改不影响快照（快照为值拷贝）。
> `update`（仅 draft）：重算 `totalScore`/校验 `passScore`、重写快照（按 questionIds 顺序）。

- [ ] **4.2 运行确认失败**；**4.3 实现**

- `startAttempt`：`exam.status === 'published'` 校验；`examAttempt.findUnique({ where: { examId_userId } })` 存在即幂等返回（转为 AttemptStartData）；不存在则 `create`（deadline = `new Date(Date.now() + durationMin*60_000)`，服务端时间）+ 快照剥离（`questionId/type/stem/options/score` 顺序返回）。并发唯一由 `@@unique([examId, userId])` 兜底（P2002 → 重查返回）。
- `submitAttempt`：归属校验（attempt.userId）；已提交 → 幂等返回首次（score/submittedAt）；未提交且 `deadlineAt < now` → `6002 '考试已结束' 422`；判分 `gradeAttempt(exam.snapshot, dto.answers)`；`update({ data: { score, answers: dto.answers, submittedAt: now } })`；返回 `SubmitData`（passed = score ≥ passScore）。
- `getResult`：未交卷 422；交卷后从 `exam.snapshot` 合并 `userAnswers/correctAnswers/analysis` 返回 `AttemptResultData`。
- `listMine`：我的考试记录（含分数/及格状态）。
- `autoSubmitExpired(now)`：查 `submittedAt=null AND deadlineAt<now` 的 attempts，逐个按 `answers ?? {}` 判分（未答计 0）落库；幂等（已提交跳过）。供步骤 12 调用。
- 路由：admin 前缀 `/admin/questions`、`/admin/exams`；用户端 `/exams`（登录，仅 published）、`/exams/:id`（登录）、`/exams/:id/attempts`（登录 + 幂等头）、`/exams/:id/attempts/:aid/submit`（登录）、`/exams/:id/attempts/:aid/result`（登录）、`/user/exams`（登录）。
