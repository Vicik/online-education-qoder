- [ ] **1.2 运行确认失败**；**1.3 实现**

```ts
async assertAllowed(content: string) {
  const words = await this.prisma.blockedWord.findMany({ where: { status: 'enabled' } });
  const lower = content.toLowerCase();
  const hits = words.filter(w => lower.includes(w.word.toLowerCase())).map(w => w.word);
  if (hits.length) throw new BizException(7001, '内容包含敏感词，请修改后重新提交', 422, hits);
}
```

> 屏蔽词每次实时查库（管理端修改立即影响用户端，项目说明文档 §3.10）。列表量小，无缓存必要。
> 管理端 CRUD：`create`（`word @unique`，重复抛 1001）、`setStatus`、`remove`；审计 `blocked_word.create/enable/disable/delete`。

- [ ] **2.2 运行确认失败**；**2.3 实现**

- `create`：`blockedWords.assertAllowed` → `sanitizeRichHtml`（帖子为纯文本 + 少量富文本，按白名单净化）→ `IdempotencyService.run(userId, key, 'POST /posts', ...)` 创建（`likeCount: 0` 默认）。
- `list`：`orderBy createdAt desc` 分页；`likedByMe`（登录时查 `post_likes` 集合 `where postId in ids and userId`）；`commentCount` = 一级+回复总数（`_count.comments`）。
- `getDetail`：帖子 + 一级评论（`parentId null`）+ 每条的回复（`parentId = 评论 id`）两层；`replyToNickname` 由 `reply_to_user_id` 联查昵称。
- `like/unlike`：事务内 `postLike.upsert/deleteMany` + `post.update({ likeCount: { increment/decrement } })`；unlike 先查存在性避免负计数（deleteMany count=0 则跳过 decrement）。
- `remove`：归属校验（他人 `2002/403`）→ `post.delete`（`comments onDelete: Cascade` 自动级联）。
