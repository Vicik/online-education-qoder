## 2. 全局约束（每步都适用，速查）

- **架构**：模块化单体（NestJS + Prisma + PostgreSQL + Redis + MinIO）+ 独立任务 Worker 进程（D1–D5、D9 已决）。
- **模块边界**：按 [目录结构.md](../目录结构.md) 划分 `auth/users/catalog/trade/promotion/exam/community/learning/audit/jobs/storage`；模块间只经内部接口（DI token）调用，共享一个数据库；用户端与管理端 controller 分离，管理端挂 `RolesGuard` + 前缀 `/api/v1/admin`。
- **统一响应包**：`{ code, message, data, requestId }`，`code=0` 成功；错误码分段 1xxx~7xxx（见接口设计文档 §5）；HTTP 状态语义化（400/401/403/404/409/422/429/500）。
- **金额**：一律整数「分」；**时间**：UTC 存储（`timestamptz`），展示按 `Asia/Shanghai`，倒计时/deadline 以服务端时间为准。
- **幂等**：创建类 POST（下单/领券/参团/发帖/秒杀/开始考试）必带 `Idempotency-Key`（8–128 字符），`idempotency_keys` 表 `(userId, key, endpoint)` 唯一，重放返回首次结果。
- **乐观锁**：管理端编辑（课程/券/拼团/秒杀/题目/考试）携带 `version`，`UPDATE ... WHERE version=?` 失败返回 409（code 见各接口）。
- **部分唯一索引适配**：Prisma 不支持 `WHERE` 部分索引，以可空唯一列实现——`orders.purchaseKey`（防重复购买）、`orders.flashPurchaseKey`（秒杀限购）、`coupon_claims.claimKey`（券限领）；创建时写入，取消/退款/失效时置 NULL。
- **会话**：Session + Redis（`HttpOnly + Secure + SameSite=Lax`）；改密/退出即时吊销；管理员仅凭邮箱密码登录（D8 已决：不启用 2FA）。
- **密码**：bcrypt `cost≥12`（D10）；策略 8–64 位（D6），统一错误提示「邮箱或密码错误」。
- **安全红线**：服务端计价（客户端不传金额）；服务端判分（答案/解析仅在交卷后返回）；富文本服务端白名单净化（sanitize-html，表格 ≤20×20）；资源归属校验防 IDOR；管理端写操作记 `audit_logs`；日志脱敏（不记密码/token/完整邮箱）。
- **演示账号**（`admin@example.com / abc12345`、`user@example.com / abc12345`）仅由种子在 dev/staging 注入，prod 不注入。
- **环境约束（本机）**：① Prisma CLI 在本机拉取引擎超时 → `migrate/generate` 一律在 CI 执行；② 本机 Docker 拉取镜像不可靠 → 依赖 testcontainers 的集成/E2E/并发测试以 CI 结果为准；**本机只保证单元测试（`npm test`）可运行**。每步「完成标准」区分「本机可验证」与「CI 验证」。
- **git**：仓库尚未初始化。`git init` 需**单独确认**，不与 add/commit 串联；各步骤中的「提交」动作均假定仓库已初始化。

## 4. 执行约定

1. **TDD 循环**：每个子任务按「写失败测试 → 运行确认失败 → 最小实现 → 运行确认通过 → 提交」执行；测试代码在步骤文档中已给出主体，允许按需补断言。
2. **提交规范**：`feat(scope): 描述` / `test(scope): 描述` / `chore: 描述`；每完成一个子任务提交一次，不攒大提交。
3. **测试分层**：单元测试（`src/**/*.spec.ts`，本机可跑）覆盖计价/判分/状态机/净化/屏蔽词等纯逻辑；集成与并发测试（`test/`）依赖真实 DB/Redis，在 CI 执行。
4. **契约对齐**：controller 路由、请求/响应结构与 `openapi.yaml` 一一对应；实现中发现契约歧义，先改设计文档再改代码。
5. **接口（DI token）约定**：后置步骤消费前置步骤产出的服务，签名以各步骤文档「接口契约」为准，不得擅自改名。
6. **每步验收**：满足该步「完成标准」（本机命令 + CI 命令），并在 CI 通过后，方可开始下一步。
