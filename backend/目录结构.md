# 知序课堂后端 目录结构说明

依据 [接口设计文档.md](./接口设计文档.md) 已决方案：**NestJS + Prisma + PostgreSQL + Redis + 本地文件存储**，模块化单体 + 独立任务 Worker（D1–D5 已决）。

---

## 1. 顶层布局

```text
backend/
├── 接口设计文档.md          # 设计依据（权威）
├── 目录结构.md              # 本文档
├── openapi.yaml             # OpenAPI 3.1 接口契约（前后端对齐依据）
├── prisma/
│   ├── schema.prisma        # 数据模型（迁移源，prisma migrate 生成 SQL）
│   ├── migrations/          # 由 `prisma migrate dev` 生成，提交入库
│   └── seed.ts              # 种子数据（dev/staging 演示数据，prod 不注入）
├── src/
│   ├── main.ts              # API 进程入口（HTTP）
│   ├── worker.ts            # Worker 进程入口（定时任务，无 HTTP）
│   ├── app.module.ts        # 装配所有业务模块
│   ├── common/              # 横切关注点（见 §2）
│   ├── config/              # 环境配置加载与校验（见 §3）
│   ├── prisma/              # PrismaService（全局单例）
│   ├── redis/               # RedisService + 会话/限流/锁封装
│   ├── storage/             # 本地文件存储：图片落盘/媒体签名/上传接口
│   ├── auth/                # 认证与会话
│   ├── users/               # 用户与资料
│   ├── catalog/             # 课程与章节
│   ├── trade/               # 订单 + 支付网关（mock，可替换）
│   ├── promotion/           # 优惠券 / 拼团 / 秒杀
│   ├── exam/                # 题库 / 考试 / 答题判分
│   ├── community/           # 帖子 / 评论 / 点赞 / 屏蔽词
│   ├── learning/            # 学习记录 / 收藏
│   ├── audit/               # 审计日志
│   └── jobs/                # Worker 定时任务（见 §4）
├── test/
│   ├── e2e/                 # 端到端（真实 DB/Redis，CI 服务或本地实例）
│   └── concurrency/         # 并发正确性（防超卖/成团竞态/幂等重放）
├── .env.example             # 环境变量模板（不含真实密钥）
├── package.json
├── tsconfig.json
└── nest-cli.json
```

## 2. 模块内部结构（每个业务模块一致）

```text
catalog/
├── catalog.module.ts        # 模块装配
├── course.service.ts        # 业务逻辑（状态机、权限矩阵）
├── course.controller.ts     # 用户端公开接口（/api/v1/courses...）
├── course.admin.controller.ts  # 管理端接口（/api/v1/admin/courses...，RolesGuard: admin）
├── dto/                     # 请求 DTO（class-validator 校验）
│   ├── create-course.dto.ts
│   └── ...
├── entities/                # 领域类型（映射 Prisma 模型，必要时加视图类型）
└── *.spec.ts                # 单元测试（与被测文件同目录）
```

约定：
- **用户端/管理端分离**：同模块内 `xxx.controller.ts`（用户端）+ `xxx.admin.controller.ts`（管理端），管理端控制器统一挂 `RolesGuard`，路由前缀 `/api/v1/admin`。
- **DTO 校验**：class-validator，白名单字段；金额用 `@IsInt`，枚举用 `@IsEnum`。
- **业务规则在 service 层**，controller 只做参数绑定与响应映射；状态机、计价、判分等纯逻辑可抽 `domain/` 子目录便于单测。
- **错误**：统一抛 `BizException(code, message, httpStatus)`，由 `common/filters` 转统一响应包。

## 3. common/ 与 config/

```text
common/
├── filters/        # 异常过滤器（BizException → 统一响应包）
├── interceptors/   # 响应包装、requestId、耗时日志
├── guards/         # SessionGuard（登录）、RolesGuard（admin）
├── decorators/     # @CurrentUser()、@Roles()、@Public()
├── pipes/          # 全局校验管道配置
├── dto/            # PageQuery、IdParam、统一分页响应类型
├── constants/      # 错误码表、枚举镜像、正则（密码/邮箱）
└── utils/          # 金额分换算、时间（Asia/Shanghai 展示）、脱敏、富文本净化
config/
└── configuration.ts # 读取并校验环境变量：DATABASE_URL、REDIS_URL、
                     # UPLOAD_*、SESSION_TTL、PAYMENT_CHANNEL=mock、限流参数等
```

`.env.example` 关键项：`DATABASE_URL`、`REDIS_URL`、`UPLOAD_DIR`、`PUBLIC_BASE_URL`、`UPLOAD_SIGNING_SECRET`、`UPLOAD_AUDIO_MAX_MB`、`UPLOAD_VIDEO_MAX_MB`、`UPLOAD_MEDIA_TTL_SECONDS`、`UPLOAD_X_ACCEL_PREFIX`、`SESSION_SECRET`、`SESSION_TTL`、`ORDER_PENDING_TTL_MINUTES=15`、`JOB_SCAN_INTERVAL_SECONDS=60`、`CORS_ORIGINS`、`BCRYPT_COST=12`、`SEED_DEMO_DATA=true`（仅 dev/staging）。

## 4. Worker 进程（jobs/）

独立入口 `worker.ts`（同一 AppModule，不 listen HTTP），按 D4「DB 定时扫描」实现，全部幂等（扫描条件 + 状态机保证）：

| 任务 | 频率建议 | 动作 |
| --- | --- | --- |
| 拼团到期扫描 | 60s | `pending` 团组到期 → 团 `failed`，成员订单 `paid→refunded`，券 `used→restored`（单事务） |
| 订单超时取消 | 60s | `pending` 且超 `ORDER_PENDING_TTL` → `cancelled`，回补秒杀预占库存、恢复券 |
| 券过期标记 | 60s | `unused/restored` 且过 `end_at` → `expired` |
| 活动状态流转 | 60s | 拼团/秒杀按起止时间 `not_started→ongoing→ended` |
| 考试兜底交卷 | 60s | `deadline_at` 已过且未提交的 attempt 自动判分交卷 |
| 秒杀库存预热 | 活动开始时 | 活动库存写入 Redis（预占计数） |

锁约定：同一时刻只允许一个 Worker 实例执行同一任务（Redis 分布式锁 `SET NX EX`），避免多实例重复处理；任务内事务与 API 事务共享连接池。

## 5. 依赖清单（拟）

- 框架：`@nestjs/core`、`@nestjs/common`、`@nestjs/platform-express`
- 数据：`prisma`、`@prisma/client`（pg 驱动）
- Redis：`ioredis`、`connect-redis`、`express-session`（D5 Session+Redis）
- 校验：`class-validator`、`class-transformer`
- 密码：`bcrypt`（cost≥12，D10）
- 存储：Node 内置 `fs/promises` 与 `crypto`（本地磁盘 + HMAC 签名）
- 富文本净化：`sanitize-html`（服务端白名单）
- 任务：`@nestjs/schedule`（配合自实现扫描器）
- 配置：`@nestjs/config`
- 测试：`jest`、`supertest`（CI 服务 + 临时目录，无容器依赖）
