## 任务 6：前端 CI

- [ ] **6.1 写 `.github/workflows/frontend-ci.yml`**

```yaml
name: frontend-ci

on:
  push:
    paths: ['frontend/**']
  pull_request:
    paths: ['frontend/**']

jobs:
  ci:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: frontend
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 24
          cache: npm
          cache-dependency-path: frontend/package-lock.json
      - run: npm ci
      - run: npm run gen:api
      - run: git diff --exit-code -- src/api/schema.d.ts
      - run: npm run lint
      - run: npm run typecheck
      - run: npm test
      - run: npm run build
```
