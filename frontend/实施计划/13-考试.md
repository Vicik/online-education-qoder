**契约修正（必须先做）**：
1. `GET /user/exams` 实际返回 `examId`（`ExamUserService.listMine`），但 `openapi.yaml` 没有 `MyExamRecord` schema、描述也未声明 `examId`。新增 schema（放在 `AttemptResultData` 之后）：

```yaml
    MyExamRecord:
      type: object
      description: 我的考试记录；未交卷时 score/passed/submittedAt 为 null
      properties:
        attemptId: { type: integer }
        examId: { type: integer }
        examTitle: { type: string }
        score: { type: integer, nullable: true }
        totalScore: { type: integer }
        passScore: { type: integer }
        passed: { type: boolean, nullable: true }
        submittedAt: { type: string, format: date-time, nullable: true }
```

2. `POST /exams/{id}/attempts` 的实现从不返回 409：重复开始直接幂等返回既有记录快照（含未交卷记录），状态码 201。将 201 描述改为「重复开始时幂等返回既有记录，不新建」，删除 409 响应块，避免前端按 `code=6001` 写死分支。

3. `POST /exams/{id}/attempts/{aid}/submit` 的实现以 attempt 状态幂等（已交卷直接返回首次判分结果），不读取 `Idempotency-Key`；**交卷不携带幂等键**，设计框架 §6.3 的适用列表也不含交卷。

4. `/user/exams` 的 200 描述改为 `data: Page（items: MyExamRecord）`。

**后端行为约定（已确认）**：
- 全部考试接口在全局 `SessionGuard` 之下，**游客返回 401**；`/exams`、`/exams/:id`、`/user/exams` 前端路由均需登录且仅 `user` 角色。
- `GET /exams` 仅返回 `published`，按 `publishedAt` 倒序；`GET /exams/:id` 对 `draft/ended` 返回 404（`code=1002`）。
- 开始考试：每人每场唯一；返回题目快照（**不含 `answer`/`analysis`**）与服务端 `deadlineAt`；已有记录（含已交卷）原样返回，计时不重置。
- 交卷：已交卷幂等返回首次 `SubmitData`；超过 `deadlineAt` 返回 `422 + code=6002`；判分完全匹配，多选无部分分。
- 成绩详情 `GET .../result`：未交卷返回 `422 + code=1001`；仅本人记录，越权 `403 + code=2002`。
- 答题过程不落库：答案只在交卷时写入；刷新或关闭页面会丢失未交卷作答，但 attempt 与截止时间不变。
- 后台 worker 会为超时未交卷记录按已有答案兜底判分（未答计 0），因此 6002 之后成绩可能稍后才可查。

```ts
// src/api/exam.ts
import { request } from './client';
import type {
  AttemptResultData,
  AttemptStartData,
  ExamBrief,
  MyExamRecord,
  PageResult,
  SubmitData,
} from './types';

// 已发布考试列表
export function listExams(page = 1, pageSize = 12): Promise<PageResult<ExamBrief>> {
  return request({ url: '/exams', method: 'GET', params: { page, pageSize } });
}

// 考试详情（不含题目与答案）
export function getExam(examId: number): Promise<ExamBrief> {
  return request({ url: `/exams/${examId}`, method: 'GET' });
}

// 开始考试：重复调用幂等返回既有记录
export function startAttempt(examId: number): Promise<AttemptStartData> {
  return request({ url: `/exams/${examId}/attempts`, method: 'POST', data: {} });
}

// 交卷：服务端按 attempt 状态幂等，不携带 Idempotency-Key
export function submitAttempt(
  examId: number,
  attemptId: number,
  answers: Record<string, string[]>,
): Promise<SubmitData> {
  return request({
    url: `/exams/${examId}/attempts/${attemptId}/submit`,
    method: 'POST',
    data: { answers },
  });
}

// 成绩与解析：仅交卷后可查
export function getAttemptResult(
  examId: number,
  attemptId: number,
): Promise<AttemptResultData> {
  return request({
    url: `/exams/${examId}/attempts/${attemptId}/result`,
    method: 'GET',
  });
}

// 我的考试记录
export function listMyExamRecords(page = 1, pageSize = 10): Promise<PageResult<MyExamRecord>> {
  return request({ url: '/user/exams', method: 'GET', params: { page, pageSize } });
}

// 本地题号作答映射转为接口载荷：丢弃未作答的空数组
export function toAnswerPayload(
  answers: Record<number, string[]>,
): Record<string, string[]> {
  // 接口载荷：题 id 字符串 -> 选项 key 数组
  const payload: Record<string, string[]> = {};
  for (const [questionId, keys] of Object.entries(answers)) {
    if (keys.length > 0) payload[questionId] = keys;
  }
  return payload;
}
```

```tsx
// src/features/exam/ExamListPage.tsx
import { useEffect, useState } from 'react';
import { Card, Pagination, Space, Typography } from 'antd';
import { Link } from 'react-router';
import { useQuery } from '@tanstack/react-query';
import { listExams } from '@/api/exam';
import { queryKeys } from '@/api/query-keys';
import { EmptyState } from '@/components/common/EmptyState';
import { PageHeader } from '@/components/common/PageHeader';
import { usePagination } from '@/hooks/usePagination';

// 列表每页数量
const PAGE_SIZE = 12;

// 考试列表：仅已发布考试
export default function ExamListPage() {
  // 当前总数（分页入参）
  const [total, setTotal] = useState(0);
  // 页码与页大小
  const { page, pageSize, onChange } = usePagination(total, PAGE_SIZE);

  // 已发布考试查询
  const query = useQuery({
    queryKey: queryKeys.exams(page),
    queryFn: () => listExams(page, pageSize),
  });

  // 同步后端总数
  useEffect(() => {
    if (query.data) setTotal(query.data.total);
  }, [query.data]);

  // 当前页考试
  const items = query.data?.items ?? [];

  return (
    <div>
      <PageHeader title="考试" />
      {items.length === 0 && !query.isLoading ? (
        <EmptyState description="暂无可参加的考试" />
      ) : (
        items.map((exam) => (
          <Card key={exam.id} style={{ marginBottom: 12 }}>
            <Space direction="vertical" style={{ width: '100%' }}>
              <Typography.Title level={4} style={{ margin: 0 }}>
                {exam.title}
              </Typography.Title>
              {exam.description && (
                <Typography.Paragraph type="secondary" style={{ marginBottom: 0 }}>
                  {exam.description}
                </Typography.Paragraph>
              )}
              <Typography.Text>时长：{exam.durationMin} 分钟</Typography.Text>
              <Typography.Text>题数：{exam.questionCount}</Typography.Text>
              <Typography.Text>
                及格分 {exam.passScore} / 总分 {exam.totalScore}
              </Typography.Text>
              <Link to={`/exams/${exam.id}`}>进入考试</Link>
            </Space>
          </Card>
        ))
      )}
      <Pagination
        current={page}
        pageSize={pageSize}
        total={total}
        onChange={onChange}
        style={{ textAlign: 'right' }}
      />
    </div>
  );
}
```

```tsx
// src/features/exam/ExamDetailPage.tsx
import { useRef, useState } from 'react';
import { App as AntdApp, Button, Card, Space, Typography } from 'antd';
import { useNavigate, useParams } from 'react-router';
import { useMutation, useQuery } from '@tanstack/react-query';
import {
  getAttemptResult,
  getExam,
  startAttempt,
  submitAttempt,
  toAnswerPayload,
} from '@/api/exam';
import type { ApiError } from '@/api/errors';
import { queryKeys } from '@/api/query-keys';
import type { AttemptResultData, AttemptStartData } from '@/api/types';
import { Countdown } from '@/components/common/Countdown';
import { EmptyState } from '@/components/common/EmptyState';
import { PageHeader } from '@/components/common/PageHeader';
import { serverNow } from '@/lib/server-clock';
import { ExamResultView } from './ExamResultView';
import { QuestionCard } from './QuestionCard';

// 页面阶段：介绍 -> 答题 -> 成绩
type ExamStage = 'intro' | 'answering' | 'result';

// 考试详情：开始考试、作答、交卷与成绩
export default function ExamDetailPage() {
  // 路由参数
  const params = useParams<{ id: string }>();
  // 考试 id
  const examId = Number(params.id);
  // 路由跳转
  const navigate = useNavigate();
  // AntD 消息与确认框
  const { modal, message } = AntdApp.useApp();
  // 当前阶段
  const [stage, setStage] = useState<ExamStage>('intro');
  // 开始考试返回（题目快照与截止时间）
  const [attempt, setAttempt] = useState<AttemptStartData | null>(null);
  // 成绩详情
  const [result, setResult] = useState<AttemptResultData | null>(null);
  // 本地作答：题 id -> 选项 key 数组
  const [answers, setAnswers] = useState<Record<number, string[]>>({});
  // 交卷守卫：手动与自动交卷只允许一次
  const submitStartedRef = useRef(false);

  // 考试详情查询
  const examQuery = useQuery({
    queryKey: queryKeys.exam(examId),
    queryFn: () => getExam(examId),
    enabled: Number.isInteger(examId) && examId > 0,
  });

  // 开始考试
  const startMutation = useMutation({ mutationFn: () => startAttempt(examId) });

  // 交卷：先提交答案，再取成绩详情
  const submitMutation = useMutation<
    AttemptResultData,
    ApiError,
    Record<number, string[]>
  >({
    mutationFn: async (payload) => {
      if (!attempt) throw new Error('考试尚未开始');
      await submitAttempt(examId, attempt.attemptId, toAnswerPayload(payload));
      return getAttemptResult(examId, attempt.attemptId);
    },
    onSuccess: (data) => {
      setResult(data);
      setStage('result');
    },
    onError: (error) => {
      // 允许在非 6002 错误后重试
      submitStartedRef.current = false;
      if (error.code === 6002) {
        message.warning('考试已结束');
        navigate('/exams');
        return;
      }
      message.error(error.message);
    },
  });

  // 交卷（手动与自动共用）
  const doSubmit = async (payload: Record<number, string[]>) => {
    if (submitStartedRef.current) return;
    submitStartedRef.current = true;
    try {
      await submitMutation.mutateAsync(payload);
    } catch {
      // 错误提示由 onError 处理
    }
  };

  // 点开始：确认后取题目并探测是否已交卷
  const handleStart = () => {
    modal.confirm({
      title: '开始考试',
      content: '开始后立即计时且不可暂停，确认开始？',
      okText: '确定',
      cancelText: '取消',
      onOk: async () => {
        try {
          const data = await startMutation.mutateAsync();
          setAttempt(data);
          try {
            const existing = await getAttemptResult(examId, data.attemptId);
            setResult(existing);
            setStage('result');
            return;
          } catch (error) {
            // 422 表示未交卷，继续答题；其他错误提示后停在介绍页
            if ((error as ApiError).status !== 422) {
              message.error((error as ApiError).message);
              return;
            }
          }
          // 已过截止时间仍未交卷：交给 worker 兜底，前端不再发交卷请求
          if (new Date(data.deadlineAt).getTime() <= serverNow()) {
            message.warning('考试已结束');
            navigate('/exams');
            return;
          }
          setStage('answering');
        } catch (error) {
          message.error((error as ApiError).message);
        }
      },
    });
  };

  // 手动作答变更
  const setAnswer = (questionId: number, keys: string[]) => {
    setAnswers((prev) => ({ ...prev, [questionId]: keys }));
  };

  // 手动交卷：未答完需二次确认
  const handleManualSubmit = () => {
    // 未作答题数
    const unanswered = (attempt?.questions ?? []).filter(
      (question) => (answers[question.id] ?? []).length === 0,
    ).length;
    modal.confirm({
      title: '确认交卷',
      content:
        unanswered > 0
          ? `还有 ${unanswered} 题未作答，交卷后不可修改，确认交卷？`
          : '交卷后不可修改，确认交卷？',
      okText: '确定',
      cancelText: '取消',
      onOk: () => doSubmit(answers),
    });
  };

  if (examQuery.isLoading) return <Card loading />;
  if (examQuery.error || !examQuery.data) {
    return (
      <EmptyState
        description="考试不存在"
        action={<Button onClick={() => navigate('/exams')}>返回考试列表</Button>}
      />
    );
  }

  // 考试详情
  const exam = examQuery.data;

  if (stage === 'result' && result) {
    return <ExamResultView result={result} onBack={() => navigate('/exams')} />;
  }

  if (stage === 'answering' && attempt) {
    return (
      <div>
        <PageHeader
          title={attempt.examTitle}
          extra={
            <Countdown
              deadlineAt={attempt.deadlineAt}
              prefix="剩余 "
              onExpire={() => void doSubmit(answers)}
            />
          }
        />
        {attempt.questions.map((question, index) => (
          <QuestionCard
            key={question.id}
            index={index + 1}
            question={question}
            value={answers[question.id] ?? []}
            onChange={(keys) => setAnswer(question.id, keys)}
          />
        ))}
        <Button
          type="primary"
          size="large"
          loading={submitMutation.isPending}
          onClick={handleManualSubmit}
        >
          交卷
        </Button>
      </div>
    );
  }

  return (
    <div>
      <PageHeader
        title={exam.title}
        extra={<Button onClick={() => navigate('/exams')}>返回列表</Button>}
      />
      <Card>
        <Space direction="vertical" size={12}>
          {exam.description && (
            <Typography.Paragraph style={{ marginBottom: 0 }}>
              {exam.description}
            </Typography.Paragraph>
          )}
          <Typography.Text>时长：{exam.durationMin} 分钟</Typography.Text>
          <Typography.Text>题数：{exam.questionCount}</Typography.Text>
          <Typography.Text>
            及格分 {exam.passScore} / 总分 {exam.totalScore}
          </Typography.Text>
          <Button type="primary" size="large" onClick={handleStart}>
            开始考试
          </Button>
        </Space>
      </Card>
    </div>
  );
}
```

```tsx
// src/features/exam/MyExamsPage.tsx
import { useEffect, useState } from 'react';
import { Tag } from 'antd';
import { Link } from 'react-router';
import { useQuery } from '@tanstack/react-query';
import { listMyExamRecords } from '@/api/exam';
import { queryKeys } from '@/api/query-keys';
import type { MyExamRecord } from '@/api/types';
import { AppTable } from '@/components/common/AppTable';
import { PageHeader } from '@/components/common/PageHeader';
import { usePagination } from '@/hooks/usePagination';
import { formatShanghai } from '@/lib/datetime';

// 我的考试每页数量
const PAGE_SIZE = 10;

// 我的考试：成绩记录与继续考试入口
export default function MyExamsPage() {
  // 当前总数（分页入参）
  const [total, setTotal] = useState(0);
  // 页码与页大小
  const { page, pageSize, onChange } = usePagination(total, PAGE_SIZE);

  // 我的考试记录查询
  const query = useQuery({
    queryKey: queryKeys.myExams(page),
    queryFn: () => listMyExamRecords(page, pageSize),
  });

  // 同步后端总数
  useEffect(() => {
    if (query.data) setTotal(query.data.total);
  }, [query.data]);

  // 表格列
  const columns = [
    { title: '考试', dataIndex: 'examTitle', key: 'examTitle' },
    {
      title: '得分',
      dataIndex: 'score',
      key: 'score',
      render: (value: number | null, record: MyExamRecord) =>
        value === null ? '未交卷' : `${value} / ${record.totalScore}`,
    },
    {
      title: '结果',
      dataIndex: 'passed',
      key: 'passed',
      render: (value: boolean | null) => {
        if (value === null) return '—';
        return <Tag color={value ? 'green' : 'red'}>{value ? '及格' : '不及格'}</Tag>;
      },
    },
    {
      title: '交卷时间',
      dataIndex: 'submittedAt',
      key: 'submittedAt',
      render: (value: string | null) => (value ? formatShanghai(value) : '—'),
    },
    {
      title: '操作',
      key: 'actions',
      render: (_: unknown, record: MyExamRecord) => (
        <Link to={`/exams/${record.examId}`}>
          {record.submittedAt ? '查看成绩' : '继续考试'}
        </Link>
      ),
    },
  ];

  return (
    <div>
      <PageHeader title="我的考试" />
      <AppTable
        columns={columns}
        dataSource={query.data?.items ?? []}
        rowKey="attemptId"
        total={total}
        page={page}
        pageSize={pageSize}
        loading={query.isLoading}
        error={query.error}
        onRetry={() => void query.refetch()}
        onPageChange={onChange}
        emptyText="还没有考试记录"
      />
    </div>
  );
}
```

## 已知边界

- 答题过程不落库（后端仅在交卷时写入答案），刷新或关闭页面会丢失未交卷作答；attempt 与截止时间保留，重新进入仍按原截止时间计时。
- 开始考试与交卷均不携带 `Idempotency-Key`：后端以「每人每场唯一记录」与 attempt 状态天然幂等；设计框架 §6.3 的适用列表也不含考试。
- 设计框架 §6.2 的「6001 跳考试成绩页」在当前后端不会触发：开始考试直接返回既有记录（含已交卷），前端以「开始后探测 `result`」实现同样的跳转效果。
- 6002 之后成绩依赖 worker 兜底判分，可能延迟可查；前端按设计框架返回列表，不自动轮询成绩。
- 未交卷记录的「继续考试」与重新开始等价，都会返回同一条 attempt 快照。
- 结果页以逐题卡片展示，不做整卷导出/打印；不做作弊检测、不做题目乱序（后端快照顺序即试卷顺序）。
