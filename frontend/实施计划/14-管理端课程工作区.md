**契约修正（必须先做）**：

1. `GET /admin/courses/{courseId}` 的实现复用用户端 `CourseDetail`，**不返回 `version`**；而 `PUT /admin/courses/{courseId}` 的 `version` 必填（`@IsInt @Min(1)`），前端无从取得版本号，设计框架 §6.4「编辑表单携带详情返回的 version」无法落地。按冲突裁决顺序（设计框架 > openapi > 后端实现），给详情补版本：

```ts
// backend/src/catalog/course.service.ts
export interface CourseDetail extends CourseBrief {
  version: number; // 乐观锁版本：管理端编辑回传，用户端忽略
  intro: string | null;
  // ...原字段不变
}

// getDetail 返回对象内追加
return {
  ...(await toCourseBrief(course, this.storage)),
  version: course.version,
  intro: course.intro,
  // ...原字段不变
};
```

`backend/src/catalog/course.service.spec.ts` 的 `getDetail` 用例：给 `prisma.course.findFirst.mockResolvedValue` 的返回追加 `version: 3`，并断言 `expect(detail.version).toBe(3)`。

2. `POST /admin/courses`、`PUT /admin/courses/{courseId}`、`publish`、`unpublish` 实际返回 Prisma `Course` 行，但 openapi 未声明响应结构。新增 `CourseAdminWriteResult`（只声明前端消费的字段；OpenAPI 允许响应多于声明字段），并把这四个响应的描述改为 `data: CourseAdminWriteResult`：

```yaml
    CourseAdminWriteResult:
      type: object
      description: 管理端课程写操作返回（课程行摘要），前端消费 id/status/version
      properties:
        id: { type: integer }
        status: { type: string, enum: [draft, published, unpublished] }
        version: { type: integer }
```

`POST /admin/courses` 的 201 与 `PUT`、`publish`、`unpublish` 的 200 响应改为显式描述：

```yaml
        '201':
          description: 'data: CourseAdminWriteResult（新建草稿）'
```

**后端行为约定（已确认）**：
- 全部 `/admin/courses*` 接口仅 `admin` 可访问；普通用户 403（`code=2002`），游客 401。
- 列表 `GET /admin/courses?page&pageSize&status?` 返回全部状态，附 `chapterCount`、`enrollmentCount`，按 `createdAt` 倒序。
- 创建固定落 `draft`；服务端校验名称 ≤40、售价 ≤ 原价；`detailRich` 服务端净化。
- 状态矩阵：`draft` 可改全部基本信息；`published` 基本信息全部不可改（先下架）；`unpublished` 仅可改讲师、封面、简介、详细介绍。
- 首章保存后类型锁定：已有章节时改 `type` 返回 422；章节 `contentType` 必须等于课程类型。
- 章节增删改排序仅在 `draft`/`unpublished` 可执行，`published` 返回 422；删除/排序后 `sortOrder` 从 1 连续重编号。
- 发布：仅 `draft`/`unpublished` 可执行，重复发布 422；下架：仅 `published` 可执行。
- 版本冲突统一 `409 + code=4004`，message 为「数据已被修改，请刷新后重试」。
- 章节接口与 `publish/unpublish` 不接收 `version`（openapi 未定义）；乐观锁只覆盖 `PUT` 基本信息。

```ts
// src/api/admin/courses.ts
import { request } from '../client';
import type {
  AdminChapter,
  AdminCourseDetail,
  AdminCourseListItem,
  ChapterCreateInput,
  ChapterUpdateInput,
  CourseCreateInput,
  CourseStatus,
  CourseUpdateInput,
  CourseWriteResult,
  PageResult,
} from '../types';

// 管理端课程列表：可选状态筛选
export function listAdminCourses(
  page = 1,
  pageSize = 10,
  status?: CourseStatus,
): Promise<PageResult<AdminCourseListItem>> {
  return request({
    url: '/admin/courses',
    method: 'GET',
    params: { page, pageSize, ...(status ? { status } : {}) },
  });
}

// 创建课程（草稿）：创建类 POST 携带幂等键
export function createCourse(
  input: CourseCreateInput,
  idempotencyKey: string,
): Promise<CourseWriteResult> {
  return request({
    url: '/admin/courses',
    method: 'POST',
    data: input,
    headers: { 'Idempotency-Key': idempotencyKey },
  });
}

// 课程详情（含草稿/已下架与 version）
export function getAdminCourse(courseId: number): Promise<AdminCourseDetail> {
  return request({ url: `/admin/courses/${courseId}`, method: 'GET' });
}

// 编辑基本信息：version 乐观锁
export function updateCourse(
  courseId: number,
  input: CourseUpdateInput,
): Promise<CourseWriteResult> {
  return request({ url: `/admin/courses/${courseId}`, method: 'PUT', data: input });
}

// 发布/重新发布
export function publishCourse(courseId: number): Promise<CourseWriteResult> {
  return request({ url: `/admin/courses/${courseId}/publish`, method: 'POST' });
}

// 下架课程
export function unpublishCourse(courseId: number): Promise<CourseWriteResult> {
  return request({ url: `/admin/courses/${courseId}/unpublish`, method: 'POST' });
}

// 新增章节：创建类 POST 携带幂等键；类型须等于课程类型
export function addChapter(
  courseId: number,
  input: ChapterCreateInput,
  idempotencyKey: string,
): Promise<AdminChapter> {
  return request({
    url: `/admin/courses/${courseId}/chapters`,
    method: 'POST',
    data: input,
    headers: { 'Idempotency-Key': idempotencyKey },
  });
}

// 编辑章节：content 缺省保持原正文
export function updateChapter(
  courseId: number,
  chapterId: number,
  input: ChapterUpdateInput,
): Promise<AdminChapter> {
  return request({
    url: `/admin/courses/${courseId}/chapters/${chapterId}`,
    method: 'PUT',
    data: input,
  });
}

// 删除章节：服务端删除后从 1 连续重编号
export function deleteChapter(courseId: number, chapterId: number): Promise<void> {
  return request({
    url: `/admin/courses/${courseId}/chapters/${chapterId}`,
    method: 'DELETE',
  });
}

// 章节排序：提交全部章节 id 的新顺序
export function reorderChapters(
  courseId: number,
  orderedChapterIds: number[],
): Promise<AdminChapter[]> {
  return request({
    url: `/admin/courses/${courseId}/chapters/reorder`,
    method: 'POST',
    data: { orderedChapterIds },
  });
}
```

```tsx
  const createMutation = useIdempotentMutation<CourseWriteResult, CourseCreateInput>(
    (payload, key) => createCourse(payload, key),
    {
      onSuccess: async (created) => {
        await queryClient.invalidateQueries({ queryKey: ['admin', 'courses'] });
        message.success('课程已保存为草稿');
        navigate(`/admin/courses/${created.id}?step=chapters`);

    // 接口载荷：富文本保存前回写图片 key
    const payload: CourseCreateInput = {
      name: values.name.trim(),
      type: values.type,
      originalCents: values.originalCents ?? 0,
      saleCents: values.saleCents ?? 0,

      coverUrl: values.cover?.key ?? null,
      intro: values.intro?.trim() || null,

            name="originalCents"
            label="原价"

          </Form.Item>
```

```tsx
// 基本信息表单值
interface BasicFormValues {
  name: string;
  type: 'video' | 'audio' | 'rich';
  originalCents: number | null;
  saleCents: number | null;
  instructor?: string;
  cover?: ImageValue | null;
  intro?: string;
  detailRich?: string;
}

// 课程类型选项
const TYPE_OPTIONS = [
  { value: 'video', label: '视频' },
  { value: 'audio', label: '音频' },
  { value: 'rich', label: '图文' },
];

// 封面回显：优先 coverKey；历史 http 地址原样作为回写值
function toCoverValue(course: AdminCourseDetail): ImageValue | null {
  // 回写值：key 或历史 http 地址
  const key = course.coverKey ?? course.coverUrl;
  return key ? { key, url: course.coverUrl } : null;
}

// 状态矩阵：与后端 EDITABLE_FIELDS 一致
function editableFields(course: AdminCourseDetail) {
  // 草稿可改全部基本信息
  const draft = course.status === 'draft';
  // 已发布全部基本信息只读
  const published = course.status === 'published';
  return {
    name: draft,
    type: draft && course.chapters.length === 0,
    originalCents: draft,
    saleCents: draft,
    instructor: !published,
    cover: !published,
    intro: !published,
    detailRich: !published,
  };
}

// 生成编辑载荷：只发送当前状态允许修改的字段，version 必带
function toUpdatePayload(
  course: AdminCourseDetail,
  values: BasicFormValues,
): CourseUpdateInput {
  // 当前状态可编辑字段
  const fields = editableFields(course);
  // 请求载荷
  const payload: CourseUpdateInput = { version: course.version };
  if (fields.name) payload.name = values.name.trim();
  if (fields.type) payload.type = values.type;
  if (fields.originalCents) payload.originalCents = values.originalCents ?? 0;
  if (fields.saleCents) payload.saleCents = values.saleCents ?? 0;
  if (fields.instructor) payload.instructor = values.instructor?.trim() || null;
  if (fields.cover) payload.coverUrl = values.cover?.key ?? null;
  if (fields.intro) payload.intro = values.intro?.trim() || null;
  if (fields.detailRich) {
    payload.detailRich = values.detailRich
      ? serializeRichHtmlForSave(values.detailRich)
      : null;
  }
  return payload;
}

// 基本信息表单：按状态矩阵禁用，保存后由父级重取详情
export function BasicInfoForm(props: {
  course: AdminCourseDetail;
  onSaved: () => Promise<void>;
  onConflict: () => void;

    mutationFn: (payload) => updateCourse(course.id, payload),
    onSuccess: async () => {
      await props.onSaved();
      message.success('基本信息已保存');
    },
    onError: (error) => {
      if (error.status === 409) {
        props.onConflict();
        return;
      }
      message.error(error.message);
    },
  });

  // 校验通过后二次确认再提交；409 关闭确认框交给刷新弹窗
  function handleFinish(values: BasicFormValues) {

  return (

        }}
        onFinish={handleFinish}
      >

            { required: true, message: '请输入课程名称' },
```

```tsx
// src/features/admin/courses/ChapterPanel.tsx
import { useState } from 'react';
import {
  Alert,
  App as AntdApp,
  Button,
  Card,
  Form,
  Input,
  List,
  Modal,
  Space,
  Typography,
} from 'antd';
import { useMutation } from '@tanstack/react-query';
import {
  addChapter,
  deleteChapter,
  reorderChapters,
  updateChapter,
} from '@/api/admin/courses';
import type { ApiError } from '@/api/errors';
import type {
  AdminChapter,
  AdminCourseDetail,
  ChapterCreateInput,
  ChapterUpdateInput,
} from '@/api/types';
import { ConfirmAction } from '@/components/common/ConfirmAction';
import { RichTextEditor } from '@/components/common/RichTextEditor';
import { useIdempotentMutation } from '@/hooks/useIdempotentMutation';
import { serializeRichHtmlForSave } from '@/lib/sanitize';

// 章节弹窗表单值
interface ChapterFormValues {
  title: string;
  content?: string;
}

// 课程类型到章节类型文案
const CONTENT_TYPE_LABEL: Record<'video' | 'audio' | 'rich', string> = {
  video: '视频',
  audio: '音频',
  rich: '图文',
};

// 章节维护：增删改与上下移动排序，已发布课程只读
export function ChapterPanel(props: {
  course: AdminCourseDetail;
  onChanged: () => Promise<void>;
  onConflict: () => void;
}) {
  // 当前课程详情
  const { course } = props;
  // AntD 消息
  const { message } = AntdApp.useApp();
  // 当前编辑的章节；null 表示新增
  const [editing, setEditing] = useState<AdminChapter | null>(null);
  // 弹窗是否打开
  const [open, setOpen] = useState(false);
  // 弹窗表单
  const [form] = Form.useForm<ChapterFormValues>();
  // 已发布课程不可维护章节
  const readOnly = course.status === 'published';

  // 写操作错误：409 走刷新提示，其余提示消息
  function handleError(error: ApiError) {
    if (error.status === 409) {
      props.onConflict();
      return;
    }
    message.error(error.message);
  }

  // 新增章节：创建类 POST 携带幂等键
  const addMutation = useIdempotentMutation<AdminChapter, ChapterCreateInput>(
    (payload, key) => addChapter(course.id, payload, key),
    {
      onSuccess: async () => {
        setOpen(false);
        await props.onChanged();
        message.success('章节已新增');
      },
      onError: handleError,
    },
  );

  // 编辑章节
  const updateMutation = useMutation<
    AdminChapter,
    ApiError,
    { chapterId: number; input: ChapterUpdateInput }
  >({
    mutationFn: ({ chapterId, input }) => updateChapter(course.id, chapterId, input),
    onSuccess: async () => {
      setOpen(false);
      await props.onChanged();
      message.success('章节已保存');
    },
    onError: handleError,
  });

  // 删除章节
  const deleteMutation = useMutation<void, ApiError, number>({
    mutationFn: (chapterId) => deleteChapter(course.id, chapterId),
    onSuccess: async () => {
      await props.onChanged();
      message.success('章节已删除');
    },
    onError: handleError,
  });

  // 排序：提交完整 id 顺序，服务端重编号
  const reorderMutation = useMutation<AdminChapter[], ApiError, number[]>({
    mutationFn: (orderedChapterIds) => reorderChapters(course.id, orderedChapterIds),
    onSuccess: async () => {
      await props.onChanged();
      message.success('排序已保存');
    },
    onError: handleError,
  });

  // 打开新增弹窗
  function openCreate() {
    setEditing(null);
    setOpen(true);
  }

  // 打开编辑弹窗：正文不回显，留空保持
  function openEdit(chapter: AdminChapter) {
    setEditing(chapter);
    setOpen(true);
  }

  // 提交弹窗：新增带 contentType；编辑仅在填写正文时提交 content
  async function handleSubmit() {
    // 表单值
    const values = await form.validateFields();
    // 去除首尾空白的标题
    const title = values.title.trim();
    // 去除首尾空白的正文
    const rawContent = values.content?.trim();
    // 空正文：空字符串与富文本空段落都视为「未填写」
    const content =
      rawContent && rawContent !== '<p></p>' ? rawContent : undefined;
    try {
      if (editing) {
        // 编辑载荷：正文留空则不带 content
        const input: ChapterUpdateInput = {
          title,
          ...(content
            ? {
                content:
                  course.type === 'rich'
                    ? serializeRichHtmlForSave(content)
                    : content,
              }
            : {}),
        };
        await updateMutation.mutateAsync({ chapterId: editing.id, input });
        return;
      }
      // 新增载荷：章节类型跟随课程类型
      const input: ChapterCreateInput = {
        title,
        contentType: course.type,
        ...(content
          ? {
              content:
                course.type === 'rich'
                  ? serializeRichHtmlForSave(content)
                  : content,
            }
          : {}),
      };
      await addMutation.mutateAsync(input);
    } catch (error) {
      // 409 已由 handleError 打开刷新弹窗，关闭当前弹窗即可
      if ((error as ApiError).status === 409) return;
      throw error;
    }
  }

  // 上移/下移：交换相邻 id 后提交完整顺序
  function move(index: number, offset: number) {
    // 当前章节 id 顺序
    const ids = course.chapters.map((chapter) => chapter.id);
    // 目标位置
    const next = index + offset;
    if (next < 0 || next >= ids.length) return;
    [ids[index], ids[next]] = [ids[next], ids[index]];
    void reorderMutation.mutateAsync(ids);
  }

  return (
    <div>
      {readOnly ? (
        <Alert
          type="warning"
          showIcon
          message="课程已发布，请先下架后再维护章节"
          style={{ marginBottom: 16 }}
        />
      ) : (
        <Button
          type="primary"
          onClick={openCreate}
          style={{ marginBottom: 16 }}
        >
          新增章节
        </Button>
      )}
      <List
        dataSource={course.chapters}
        locale={{ emptyText: '还没有章节' }}
        renderItem={(chapter, index) => (
          <Card key={chapter.id} style={{ marginBottom: 12 }}>
            <Space direction="vertical" style={{ width: '100%' }}>
              <Typography.Text strong>
                {chapter.sortOrder}. {chapter.title}
              </Typography.Text>
              <Typography.Text type="secondary">
                内容类型：{CONTENT_TYPE_LABEL[chapter.contentType]}
              </Typography.Text>
              {!readOnly && (
                <Space>
                  <Button
                    size="small"
                    disabled={index === 0}
                    onClick={() => move(index, -1)}
                  >
                    上移
                  </Button>
                  <Button
                    size="small"
                    disabled={index === course.chapters.length - 1}
                    onClick={() => move(index, 1)}
                  >
                    下移
                  </Button>
                  <Button size="small" onClick={() => openEdit(chapter)}>
                    编辑
                  </Button>
                  <ConfirmAction
                    title="删除章节"
                    content={`删除「${chapter.title}」后其余章节将从 1 重新编号，确认删除？`}
                    danger
                    onConfirm={async () => {
                      try {
                        await deleteMutation.mutateAsync(chapter.id);
                      } catch (error) {
                        // 409 由 handleError 打开刷新弹窗，确认框直接关闭
                        if ((error as ApiError).status === 409) return;
                        throw error;
                      }
                    }}
                  >
                    <Button size="small" danger>
                      删除
                    </Button>
                  </ConfirmAction>
                </Space>
              )}
            </Space>
          </Card>
        )}
      />

      <Modal
        title={editing ? '编辑章节' : '新增章节'}
        open={open}
        destroyOnClose
        confirmLoading={addMutation.isPending || updateMutation.isPending}
        onOk={() => void handleSubmit()}
        onCancel={() => setOpen(false)}
      >
        <Form<ChapterFormValues>
          key={editing ? `edit-${editing.id}` : 'create'}
          form={form}
          layout="vertical"
          initialValues={{ title: editing?.title ?? '', content: '' }}
        >
          <Form.Item
            name="title"
            label="章节标题"
            rules={[
              { required: true, message: '请输入章节标题' },
              { max: 60, message: '最多 60 个字符' },
            ]}
          >
            <Input />
          </Form.Item>
          <Form.Item label="内容类型">
            <Input value={CONTENT_TYPE_LABEL[course.type]} disabled />
          </Form.Item>
          <Form.Item
            name="content"
            label="正文"
            extra={
              editing
                ? '留空保持原正文不变，填写则整体替换'
                : '可选；图文为富文本，视频/音频为对象存储 key'
            }
          >
            {course.type === 'rich' ? (
              <RichTextEditor placeholder="留空保持原正文不变" />
            ) : (
              <Input placeholder="对象存储 key，留空保持原正文不变" />
            )}
          </Form.Item>
        </Form>
      </Modal>
    </div>
  );
}
```

```tsx
// src/features/admin/courses/CourseWorkspacePage.tsx
import { App as AntdApp, Button, Card, Segmented, Space } from 'antd';
import { useNavigate, useParams, useSearchParams } from 'react-router';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { getAdminCourse, publishCourse, unpublishCourse } from '@/api/admin/courses';
import type { ApiError } from '@/api/errors';
import { queryKeys } from '@/api/query-keys';
import type { CourseWriteResult } from '@/api/types';
import { ConfirmAction } from '@/components/common/ConfirmAction';
import { EmptyState } from '@/components/common/EmptyState';
import { PageHeader } from '@/components/common/PageHeader';
import { StatusTag } from '@/components/common/StatusTag';
import { BasicInfoForm } from './BasicInfoForm';
import { ChapterPanel } from './ChapterPanel';

// 工作区两步：基本信息 / 章节维护
type Step = 'basics' | 'chapters';

// 步骤选项
const STEP_OPTIONS = [
  { label: '基本信息', value: 'basics' },
  { label: '章节维护', value: 'chapters' },
];

// 课程工作区：两步互斥切换、发布/下架与版本冲突刷新
export default function CourseWorkspacePage() {
  // 路由参数
  const params = useParams<{ id: string }>();
  // 课程 id
  const courseId = Number(params.id);
  // 路由跳转
  const navigate = useNavigate();
  // URL 查询参数：保存当前步骤，刷新后保持
  const [searchParams, setSearchParams] = useSearchParams();
  // 当前步骤
  const step: Step = searchParams.get('step') === 'chapters' ? 'chapters' : 'basics';
  // AntD 消息与确认框
  const { modal, message } = AntdApp.useApp();
  // Query 缓存
  const queryClient = useQueryClient();

  // 课程详情查询
  const query = useQuery({
    queryKey: queryKeys.adminCourse(courseId),
    queryFn: () => getAdminCourse(courseId),
    enabled: Number.isInteger(courseId) && courseId > 0,
  });

  // 重取详情并刷新管理端课程缓存
  async function refreshCourse() {
    await queryClient.invalidateQueries({ queryKey: ['admin', 'courses'] });
  }

  // 版本冲突：只提示刷新，不自动覆盖
  function handleConflict() {
    modal.confirm({
      title: '内容已在其他页面被修改，请刷新后重试',
      content: '刷新将载入最新数据，本次未保存的修改会丢失。',
      okText: '刷新',
      cancelText: '关闭',
      onOk: refreshCourse,
    });
  }

  // 发布：确认后调用；冲突交给刷新弹窗，其余错误由确认框提示
  const publishMutation = useMutation<CourseWriteResult, ApiError, void>({
    mutationFn: () => publishCourse(courseId),
    onSuccess: async () => {
      await refreshCourse();
      message.success('课程已发布');
    },
  });

  // 下架
  const unpublishMutation = useMutation<CourseWriteResult, ApiError, void>({
    mutationFn: () => unpublishCourse(courseId),
    onSuccess: async () => {
      await refreshCourse();
      message.success('课程已下架');
    },
  });

  // 打开确认框并调用发布/下架；409 转为刷新提示
  async function confirmStatusChange(action: () => Promise<unknown>) {
    try {
      await action();
    } catch (error) {
      if ((error as ApiError).status === 409) {
        handleConflict();
        return;
      }
      throw error;
    }
  }

  if (query.isLoading) return <Card loading />;
  if (query.error || !query.data) {
    return (
      <EmptyState
        description="课程不存在"
        action={
          <Button onClick={() => navigate('/admin/courses')}>返回课程列表</Button>
        }
      />
    );
  }

  // 当前课程详情
  const course = query.data;

  return (
    <div>
      <PageHeader
        title={course.name}
        extra={
          <Space>
            <StatusTag domain="course" status={course.status} />
            {(course.status === 'draft' || course.status === 'unpublished') && (
              <ConfirmAction
                title="发布课程"
                content="发布后课程对用户可见，确认发布？"
                onConfirm={() =>
                  confirmStatusChange(() => publishMutation.mutateAsync())
                }
              >
                <Button type="primary">发布</Button>
              </ConfirmAction>
            )}
            {course.status === 'published' && (
              <ConfirmAction
                title="下架课程"
                content="下架后用户不可新购买，已购用户仍可学习，确认下架？"
                danger
                onConfirm={() =>
                  confirmStatusChange(() => unpublishMutation.mutateAsync())
                }
              >
                <Button danger>下架</Button>
              </ConfirmAction>
            )}
            <Button onClick={() => navigate('/admin/courses')}>返回列表</Button>
          </Space>
        }
      />

      <Segmented
        options={STEP_OPTIONS}
        value={step}
        onChange={(value) => setSearchParams({ step: String(value) })}
        style={{ marginBottom: 16 }}
      />

      <Card>
        {step === 'basics' ? (
          <BasicInfoForm
            course={course}
            onSaved={refreshCourse}
            onConflict={handleConflict}
          />
        ) : (
          <ChapterPanel
            course={course}
            onChanged={refreshCourse}
            onConflict={handleConflict}
          />
        )}
      </Card>
    </div>
  );
}
```

## 已知边界

- **章节正文不可回显**：后端没有管理端章节详情接口，课程详情的 `chapters` 只有 id/标题/类型/序号。编辑弹窗正文留空表示保持原内容，填写则整体替换；建议后端后续补 `GET /admin/courses/:id/chapters/:cid`。本章节以该边界交付，不伪造正文。
- 章节增删改排序与 `publish/unpublish` 接口都不接收 `version`；乐观锁只覆盖 `PUT` 基本信息。设计框架「所有写操作带 version」在这些动作上以服务端状态校验（422）与 409 兜底，前端不再自行发明参数。
- 课程详情的 `version` 是本次契约修正新增字段，用户端详情也会返回但页面不使用；不要在前端缓存中跨课程复用。
- 已发布课程必须先下架才能改基本信息与章节；前端只做禁用与提示，最终由后端 422 兜底。
- 列表只有状态筛选，没有关键词/讲师搜索（后端无参数）；前端不伪造本地筛选。
- 删除章节与排序后由服务端从 1 连续重编号；前端以重取详情为准，不做本地顺序推算。
- 富文本保存前会把图片 `src` 回写为 `data-key`；历史无 `data-key` 的图片保持原地址。图片签名过期沿用步骤 05 的 `onError` 触发重取策略。
