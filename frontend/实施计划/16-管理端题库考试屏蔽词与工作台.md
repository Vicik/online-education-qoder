**契约修正（必须先做）**：

1. 题目管理端视图实际返回 `version`、`createdAt`、`updatedAt`，但 openapi 只声明了答案/解析/状态。补全后管理端才能携带版本号编辑并展示更新时间：

```yaml
    QuestionAdminView:
      allOf:
        - $ref: '#/components/schemas/QuestionUserView'
        - type: object
          properties:
            answer: { type: array, items: { type: string }, description: 单选恰好 1 个；多选 ≥2 个 }

            version: { type: integer, description: 乐观锁版本（管理端编辑回传） }

            updatedAt: { type: string, format: date-time }
```

2. 考试详情实际返回 `ExamBrief + { version, questionIds }`，openapi 只有一句文字描述，生成类型拿不到 `version`/`questionIds`。新增命名 schema 并让写操作响应描述指向它：

```yaml

        - type: object
          properties:
            version: { type: integer, description: 乐观锁版本（管理端编辑回传） }

              type: array
              items: { type: integer }
              description: 组卷题目 id，按出题顺序
```

**后端行为约定（已确认）**：
- 四组接口全部仅 `admin` 可访问；游客 401，普通用户 403（`code=2002`）。
- 题目列表支持 `type=single|multiple`、`status=enabled|disabled`，按创建时间倒序，返回答案与解析。
- 题目创建默认启用；选项 2–6 个、key 非空且唯一、text 非空；单选恰 1 个答案、多选 ≥2 个；答案必须来自选项且不可重复；分值 ≥1 且仅创建时确定。
- 题目编辑 `version` 必填且必须匹配，否则 409 + `code=4004`；请求里的 `score` 被服务端忽略；题型可改，但改后答案数量必须满足新题型规则。
- 题目启用/停用接口不接收 `version`，后端每次自增版本；并发状态变化以服务端当前状态为准，不做叠加校验。
- 考试列表返回全部状态，按创建时间倒序，**没有状态筛选参数**。
- 考试创建为草稿：题目按 `questionIds` 顺序写入快照，至少 1 道、不可重复、必须存在且启用；总分=题目分值之和；及格分 >0 且 ≤总分。
- 考试编辑仅草稿可执行，`version` 必填；重新传 `questionIds` 会按新顺序重建快照并重算总分；发布后不可编辑。
- 发布仅草稿可执行，冻结含答案/解析的题目快照并重算总分；结束仅已发布可执行；发布/结束都不接收 `version`。
- 屏蔽词列表支持 `status` 过滤；新增去首尾空白、词唯一，重复返回 409 + `code=1001`（message「屏蔽词已存在」）；更新/删除返回 `data: null`。
- 工作台 `GET /admin/dashboard/stats` 后端尚未实现（openapi 有路径与 `DashboardStats` schema）；本步不请求该接口。

```ts
import type {
  AdminQuestion,
  AdminQuestionType,
  QuestionCreateInput,
  QuestionUpdateInput,
} from '@/api/types';

// 选项表单值
export interface QuestionOptionValue {
  key: string;
  text: string;
}

// 题目表单值
export interface QuestionFormValues {
  type: AdminQuestionType;
  stem: string;
  options: QuestionOptionValue[];
  answer: string[];
  score: number;
  analysis: string;
}

// 界面固定使用的选项 key 序列
const OPTION_KEYS = ['A', 'B', 'C', 'D', 'E', 'F'] as const;

// 取下一个未占用的选项 key；已满则回退 A（按钮同时禁用）
export function nextOptionKey(options: QuestionOptionValue[]): string {
  // 当前已占用 key
  const used = new Set(options.map((option) => option.key));
  return OPTION_KEYS.find((key) => !used.has(key)) ?? 'A';
}

// 选项 → 答案选择项：标签带 key，便于用户与测试定位
export function buildAnswerOptions(options: QuestionOptionValue[]) {
  return options.map((option) => ({
    value: option.key,
    label: `${option.key}. ${option.text}`,
  }));
}

// 创建载荷：去首尾空白；分值只在创建时提交
export function toQuestionCreatePayload(
  values: QuestionFormValues,
): QuestionCreateInput {
  return {
    type: values.type,
    stem: values.stem.trim(),
    options: values.options.map((option) => ({
      key: option.key,
      text: option.text.trim(),
    })),
    answer: values.answer,
    analysis: values.analysis.trim(),
    score: values.score,
  };
}

// 编辑载荷：携带 version；不提交 score（服务端也会忽略）
export function toQuestionUpdatePayload(
  values: QuestionFormValues,
  version: number,
): QuestionUpdateInput {
  return {
    version,
    type: values.type,
    stem: values.stem.trim(),
    options: values.options.map((option) => ({
      key: option.key,
      text: option.text.trim(),
    })),
    answer: values.answer,
    analysis: values.analysis.trim(),
  };
}

// 详情 → 表单值
export function toQuestionFormValues(question: AdminQuestion): QuestionFormValues {
  return {
    type: question.type ?? 'single',
    stem: question.stem ?? '',
    options: (question.options ?? []).map((option) => ({
      key: option.key ?? '',
      text: option.text ?? '',
    })),
    answer: question.answer ?? [],
    score: question.score ?? 1,
    analysis: question.analysis ?? '',
  };
}
```

```tsx
import type { ApiError } from '@/api/errors';
import type { AdminQuestion, QuestionUpdateInput } from '@/api/types';

import {
  toQuestionFormValues,
  toQuestionUpdatePayload,
  type QuestionFormValues,

// 编辑题目：分值只读；409 只提示刷新
export default function QuestionEditPage() {
  // 路由参数
  const params = useParams();
  // 题目 id
  const questionId = Number(params.id);
  // 返回列表
  const navigate = useNavigate();
  // AntD 消息与确认框
  const { modal, message } = AntdApp.useApp();
  // 查询缓存
  const queryClient = useQueryClient();

  // 题目详情
  const query = useQuery({
    queryKey: queryKeys.adminQuestion(questionId),
    queryFn: () => getAdminQuestion(questionId),
    enabled: Number.isInteger(questionId) && questionId > 0,
  });

  // 版本冲突：刷新详情，不自动覆盖
  function showConflict() {
    modal.confirm({
      title: '内容已在其他页面被修改，请刷新后重试',
      content: '刷新将载入最新数据，本次未保存的修改会丢失。',
      okText: '刷新',
      cancelText: '关闭',
      onOk: () => query.refetch(),
    });
  }

  // 保存题目：携带 version
  const updateMutation = useMutation<
    AdminQuestion,
    ApiError,
    QuestionUpdateInput
  >({
    mutationFn: (input) => updateQuestion(questionId, input),
    onSuccess: async (updated) => {
      queryClient.setQueryData(queryKeys.adminQuestion(questionId), updated);
      await queryClient.invalidateQueries({ queryKey: ['admin', 'questions'] });
      message.success('题目已保存');
    },
    onError: (error) => {
      if (error.status === 409) {
        showConflict();
        return;
      }
      message.error(error.message);
    },
  });

  // 校验通过后二次确认
  function handleSubmit(values: QuestionFormValues) {
    modal.confirm({
      title: '保存题目',
      content: '保存后立即生效，确认保存？',
      okText: '确认保存',
      cancelText: '取消',
      onOk: () =>
        updateMutation.mutateAsync(
          toQuestionUpdatePayload(values, query.data!.version ?? 1),
        ),
    });
  }

  if (query.isLoading) {
    return <Spin />;
  }

  if (query.error || !query.data) {
    return (
      <EmptyState
        description="题目加载失败"
        action={<Button onClick={() => void query.refetch()}>重试</Button>}
      />
    );
  }

  return (
    <div>
      <PageHeader title="编辑题目" />
      <Card>

            type="warning"
            showIcon

          key={query.data.version}
          mode="edit"
          initialValues={toQuestionFormValues(query.data)}
          submitting={updateMutation.isPending}
          onSubmit={handleSubmit}
          onCancel={() => navigate('/admin/questions')}
        />
      </Card>
    </div>
  );
}
```

```ts
import type {
  AdminExamDetail,
  AdminQuestion,
  ExamCreateInput,
  ExamUpdateInput,

// 考试表单值
export interface ExamFormValues {
  title: string;
  description?: string;
  durationMin: number;
  passScore: number;
  questionIds: number[];
}

// 按出题顺序计算总分
export function totalScoreOf(
  questions: AdminQuestion[],
  questionIds: number[],
): number {
  // 题目 id → 分值
  const scoreById = new Map(questions.map((question) => [question.id, question.score ?? 0]));
  return questionIds.reduce((sum, id) => sum + (scoreById.get(id) ?? 0), 0);
}

// 创建载荷：按选择顺序提交题目 id
export function toExamCreatePayload(values: ExamFormValues): ExamCreateInput {
  return {
    title: values.title.trim(),
    description: values.description?.trim() ?? '',
    durationMin: values.durationMin,
    passScore: values.passScore,
    questionIds: values.questionIds,
  };
}

// 编辑载荷：携带 version
export function toExamUpdatePayload(
  values: ExamFormValues,
  version: number,
): ExamUpdateInput {
  return {
    version,
    title: values.title.trim(),
    description: values.description?.trim() ?? '',
    durationMin: values.durationMin,
    passScore: values.passScore,
    questionIds: values.questionIds,
  };
}
```

```tsx
import { Button, Tag, Typography } from 'antd';
import type { AdminQuestion } from '@/api/types';

// 已选题目顺序列表：上移/下移/移除；只读时隐藏操作
export function QuestionOrderList(props: {
  questions: AdminQuestion[];
  value: number[];
  onChange: (questionIds: number[]) => void;
  readOnly?: boolean;
}) {
  // 题目 id → 题目
  const byId = new Map(props.questions.map((question) => [question.id, question]));

  // 交换相邻题目
  function move(from: number, to: number) {
    if (to < 0 || to >= props.value.length) return;
    const next = [...props.value];
    [next[from], next[to]] = [next[to], next[from]];
    props.onChange(next);
  }

  if (props.value.length === 0) {
    return <Typography.Text type="secondary">尚未选择题目</Typography.Text>;
  }

  return (
    <div style={{ marginBottom: 16 }}>
      {props.value.map((questionId, index) => {
        // 当前题目
        const question = byId.get(questionId);
        return (
          <div
            key={questionId}
            data-testid={`question-order-${questionId}`}
            style={{ display: 'flex', alignItems: 'center', gap: 8, marginBottom: 8 }}
          >
            <Typography.Text ellipsis style={{ flex: 1 }}>
              {index + 1}. {question?.stem ?? `题目 ${questionId}`}（
              {question?.score ?? 0} 分）
            </Typography.Text>
            {question?.status === 'disabled' && <Tag>已停用</Tag>}
            {!props.readOnly && (
              <>
                <Button
                  size="small"
                  disabled={index === 0}
                  onClick={() => move(index, index - 1)}
                >
                  上移
                </Button>
                <Button
                  size="small"
                  disabled={index === props.value.length - 1}
                  onClick={() => move(index, index + 1)}
                >
                  下移
                </Button>

                  size="small"
                  danger
                  onClick={() =>
                    props.onChange(props.value.filter((id) => id !== questionId))
                  }

                  移除
```

```tsx
export default function BlockedWordListPage() {
  // AntD 消息
  const { message } = AntdApp.useApp();
  // 查询缓存
  const queryClient = useQueryClient();
  // 状态筛选
  const [status, setStatus] = useState<BlockedWordStatus | 'all'>('all');
  // 当前总数
  const [total, setTotal] = useState(0);
  // 分页
  const { page, pageSize, onChange } = usePagination(total, PAGE_SIZE);
  // 弹窗开关
  const [open, setOpen] = useState(false);
  // 正在编辑的词；null 表示新增
  const [editing, setEditing] = useState<AdminBlockedWord | null>(null);

  // 列表查询
  const query = useQuery({
    queryKey: queryKeys.adminBlockedWords(`${page}:${pageSize}:${status}`),
    queryFn: () =>
      listBlockedWords(
        page,
        pageSize,
        status === 'all' ? undefined : status,
      ),
  });

  // 同步总数
  useEffect(() => {
    if (query.data) setTotal(query.data.total);
  }, [query.data]);

  // 新增
  const createMutation = useIdempotentMutation<
    AdminBlockedWord,
    BlockedWordCreateInput
  >((payload, key) => createBlockedWord(payload, key), {
    onSuccess: async () => {
      await queryClient.invalidateQueries({ queryKey: ['admin', 'blocked-words'] });
      message.success('屏蔽词已新增');
    },
  });

    void,
    ApiError,
    { id: number; input: BlockedWordUpdateInput }

    mutationFn: ({ id, input }) => updateBlockedWord(id, input),
    onSuccess: async () => {
      await queryClient.invalidateQueries({ queryKey: ['admin', 'blocked-words'] });
      message.success('屏蔽词已更新');
    },
    onError: (error) => message.error(error.message),
  });

    mutationFn: (id) => deleteBlockedWord(id),
    onSuccess: async () => {
      await queryClient.invalidateQueries({ queryKey: ['admin', 'blocked-words'] });
      message.success('屏蔽词已删除');
    },
    onError: (error) => message.error(error.message),
  });

  async function save(values: BlockedWordFormValues) {

            size="small"
```

## 已知边界

- **题目没有删除接口**：题库只支持启停与编辑。停用后不再进入组卷候选，但历史考试快照不受影响；前端不提供删除按钮，也不伪造本地删除。
- **题目答案 key 由界面固定为 A–F**：后端允许任意非空且唯一的 key，界面统一用 A–F 自动补位，避免自定义 key 导致的答案错配；如需自定义 key，后续再扩展契约。
- **题目启停不带 `version`**：openapi 未定义请求体，前端不发明参数；并发启停以服务端当前状态为准，最后一次请求生效。
- **考试没有状态筛选**：后端列表接口只支持分页，管理端只能按创建时间倒序浏览；考试数量大时需先补后端筛选参数。
- **组卷候选最多 100 道**：后端题目列表 `pageSize` 上限 100，且没有搜索参数；题目超过 100 道时，未加载的题目无法在组卷下拉中选择。已选但不在前 100 的题目仍按 id 显示在顺序列表中。
- **停用题目会阻止草稿保存**：后端组卷要求题目全部存在且启用；若草稿中的题目在题库被停用，保存时返回 422，需先从顺序列表移除该题。界面会对已选停用题打「已停用」标记。
- **考试发布不可撤销**：没有「取消发布/撤回」接口；发布冻结快照，结束仅已发布可执行，结束后不可恢复。
- **屏蔽词无 `version`**：并发修改以最后一次写入为准；409 在本模块只代表「词重复」，因此行内提示而不是刷新弹窗。
- **工作台接口未实现**：`GET /admin/dashboard/stats` 与 `DashboardStats` schema 已在 openapi 中，但后端没有控制器。本步按设计框架「一期占位卡片」交付，不请求接口；接入时新增 `api/admin/dashboard.ts` 的 `getDashboardStats()` 与 `dashboardStats` 查询键即可，页面结构无需重写。
- **E2E 未执行**：本机 Docker 不可靠，真实后端链路以 CI 或具备后端环境时的结果为准。
